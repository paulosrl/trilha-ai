# CLAUDE-curso.md

Versão 1.2, de 2026-10-12. Não edite este arquivo: o que é deste repositório vai no `CLAUDE.md`.

Regras de um repositório usado como **material de curso**. O `CLAUDE.md` o importa com `@CLAUDE-curso.md`. O objetivo é a prova: como o processo aconteceu, prompt por prompt.

## Documentar cada etapa, no mesmo turno

Ao concluir qualquer etapa, ou ao pausar no meio de uma:

1. registrar no documento do processo (nome no `CLAUDE.md`) o prompt literal do usuário, sem corrigir a digitação, o que foi feito, o que saiu (arquivos e commits), as decisões humanas e os incidentes; atualizar a linha do tempo e o "Onde estamos agora";
2. atualizar o resumo, com links que funcionam;
3. regenerar e republicar a página da documentação, se o repositório tiver uma;
4. fazer o commit junto com a etapa.

- Uma pergunta respondida e uma pausa também são etapas.
- Nada reconstruído se apresenta como literal; o que não tem registro é marcado como reconstruído.
- No material de ensino, o prompt literal é citado por apontamento ao registro; o que o aluno copia é a receita limpa.
